JSS 3
I Solve Problems With Code

Project-based programming and BECE/WAEC readiness.

Age 14–15 years 3 Terms 8 Weeks per Term
Term-by-Term Curriculum

Every Week,
Something Built.

No theory-only sessions — every week ends with something the student made, built, typed, or designed. Select a term to see its full breakdown.

1

Python Review

Speed quiz, 20 questions in 15 minutes, covering all JSS1–2 concepts.

✓ Demonstrates retained Python knowledge
2

OOP Concepts

Classes and objects via a real-life analogy (a car); attributes and methods.

✓ Explains OOP in plain terms
3

Classes in Python

Student class (name, age, score); instantiate 3 objects.

✓ Writes a Python class
4

Methods

Method to calculate and print grade automatically.

✓ Creates and calls class methods
5

Library Book Tracker

Add, return, list, and search books — class-based app.

✓ Builds a class-based application
6

Error Handling

try/except for bad input.

✓ Uses try/except correctly
7

Classes + File Handling

Save and load library data to a .txt file; persists between sessions.

✓ Combines classes with file I/O
8

School Fee Tracker (class exercise)

A fictional programme that records student names, fee payments per term, calculates outstanding balance, and saves to file — a coding exercise, not EduLab's own pricing.

✓ Builds a data-tracking tool
End of Term 1 Project

School Fee Tracker

A Python programme (classes + file handling) that records fee payments per term, tracks outstanding balance, and saves/loads data. A coding exercise using fictional data.

HTML Forms

CSS Advanced

JavaScript Intro

JavaScript — Variables & Logic

JavaScript Quiz

CBT Exam Technique

Quiz Website Project

HTML/CSS/JS quiz, own topic, 10+ questions, auto scoring, result message.

✓ Deploys a complete interactive quiz
