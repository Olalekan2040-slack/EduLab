JSS 2
I Build Things That Work

Real programming projects and web design foundations.

Age 13–14 years 3 Terms 8 Weeks per Term
Term-by-Term Curriculum

Every Week,
Something Built.

No theory-only sessions — every week ends with something the student made, built, typed, or designed. Select a term to see its full breakdown.

1

Python — Lists

Create, add, remove, loop through a name list; alphabetical sort.

✓ Uses lists with common methods
2

Python — Dictionaries

Student profile dictionary (name, age, class, score); access and update.

✓ Creates and queries dictionaries
3

Python — Functions

Define and call functions, arguments, return values; grade calculator function.

✓ Writes and calls functions
4

BMI Calculator

Multi-function BMI calculator (height, weight → category).

✓ Builds a multi-function programme
5

String Methods

upper(), lower(), replace(), split(), strip(), len() on messy name data.

✓ Applies 5+ string methods
6

File Handling

Write, read, and append student names to a .txt file.

✓ Reads and writes text files
7

Contact Book App

Lists, dictionaries, and functions: add, view, search contacts.

✓ Builds a complete mini-application
8

Result Calculator Project

5 students x 3 subject scores; average, grade A–F, formatted slip.

✓ Produces a formatted results programme
End of Term 1 Project

Student Result Calculator

A Python programme for 5 students with 3 scores each, calculating average, grade A–F, and formatted result slips.

1

What is a Website?

HTML structure (html, head, body); first webpage; view source.

✓ Creates and views first HTML page
2

HTML — Text & Structure

Headings h1–h6, paragraphs, breaks, hr; school page with 3 sections.

✓ Structures content with HTML tags
3

HTML — Links & Images

Anchor tags, alt text, ul/ol lists; top-5 favourites page.

✓ Adds links, images, and lists
4

HTML Tables

table, tr, th, td; class timetable; border and colour via style.

✓ Creates a structured HTML table
5

CSS — Colours & Fonts

External CSS; background/text colour, font family/size; style timetable.

✓ Links and applies a CSS stylesheet
6

CSS — Box Model

Background, borders, padding, margin; personal profile card.

✓ Understands and applies box model
7

Product Design — Brief & Wireframe

Define audience, purpose, content for personal website; paper wireframe.

✓ Produces a design brief and wireframe
8

Personal Website

Styled 2-page HTML/CSS site — home and interests/school pages.

✓ Publishes a working personal website
End of Term 2 Project

My Personal Website

A styled 2-page HTML/CSS site with headings, images, links, a nav menu, and CSS, based on the wireframe.

1

Database Concepts

Tables, records, fields, primary keys; school register example.

✓ Explains database terminology
2

Spreadsheet as Database

Sheets student database: data validation, dropdowns, locked header.

✓ Builds a structured data table
3

Advanced Formulas

IF, COUNTIF, SUMIF (pass counts, threshold sums, flag failures).

✓ Uses conditional formulas correctly
4

VLOOKUP

Search student by ID for name, class, score; exact vs approximate match.

✓ Uses VLOOKUP to query data
5

Pivot Tables

Summarise 30 students' results by subject and grade.

✓ Creates a pivot table analysis
6

Dashboard Design

Combine VLOOKUP, pivot table, and 2 charts on one Dashboard sheet.

✓ Builds a one-page data dashboard
7

SQL Concepts

SELECT, FROM, WHERE, ORDER BY on paper; English-to-SQL matching.

✓ Writes basic SQL queries on paper
8

School Results Dashboard

Complete Sheets dashboard: 30 records, VLOOKUP tool, pivot summary, visuals.

✓ Delivers a complete data dashboard
End of Term 3 Project

School Results Dashboard

A Sheets file with 30 student records, a VLOOKUP tool, a pivot table, and a professional dashboard sheet.
