JSS 2
Python Programming and Problem Solving

Open to new learners at this class level. Starts programming at beginner level; does not rely on JSS1 web development.

Age 13–14 years 3 Terms 8 Weeks per Term Tools Python 3
Term-by-Term Curriculum

Every Week,
Something Built.

Learners complete three term projects, store their work in a class portfolio, and explain the safety and practical skills used. Select a term to see its full breakdown.

Term outcome: Write small programs using variables, input and decisions.
1

Getting started with Python

Run Python, print text and save a script.

2

Variables and types

Use strings, integers and simple conversions.

3

Input and output

Ask user for name, class and subjects.

4

Arithmetic

Calculate sums, time totals and percentages.

5

Conditions

Make decisions with if/elif/else.

6

Loops

Use for and while loops safely.

7

Functions and debugging

Break program into functions and test sample inputs.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 1 Assessed Project

Student Study Planner

Python console app asking subjects and displaying a study plan.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Term outcome: Organise data with lists and dictionaries.
1

Python refresher

Revisit variables, loops, input and functions.

2

Lists

Store subject names and scores.

3

List operations

Append, remove, iterate and sort.

4

Dictionaries

Create a student record using keys and values.

5

Nested data

Store several subjects for one student.

6

Calculations and grading

Calculate mean and grade boundaries.

7

Error handling and testing

Handle missing or invalid numeric inputs.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 2 Assessed Project

Student Result Calculator

Python program that stores scores and calculates totals, averages and grades.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Term outcome: Plan, build, test and explain a complete program.
1

Program brief

Identify inputs, outputs and sample users.

2

Modules and files

Read/write simple CSV or text records.

3

Data design

Plan book title, ID and availability fields.

4

Functions and menu

Add, find, borrow and return actions.

5

Validation

Prevent blank entries and duplicate IDs.

6

Testing

Prepare and run at least 8 test cases.

7

Documentation

Write usage guide and demonstrate.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 3 Assessed Project

School Library Inventory

Console-based lending register with search and file save.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Annual portfolio requirement: Three finished projects (editable files where available), three final exports or screenshots, a weekly skills checklist, and a short learner reflection on what they can now do independently.
