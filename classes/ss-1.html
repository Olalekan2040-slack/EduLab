SS 1
Python Applications and Web Foundations

Open to new learners at this class level. Begins coding fundamentals within the class and moves from scripts to local web applications.

Age 15–16 years 3 Terms 8 Weeks per Term Tools Python, Flask & SQLite
Term-by-Term Curriculum

Every Week,
Something Built.

Learners complete three term projects, store their work in a class portfolio, and explain the safety and practical skills used. Select a term to see its full breakdown.

WAEC/CBT Readiness Portfolio

Spreadsheet, timed practice reflection and 2 documented coding samples.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.
