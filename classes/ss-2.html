SS 2
I Am Ready for the World

Employable skills, freelancing, capstone project, and JAMB readiness.

Age 16–18 years 3 Terms 8 Weeks per Term
Term-by-Term Curriculum

Every Week,
Something Built.

No theory-only sessions — every week ends with something the student made, built, typed, or designed. Select a term to see its full breakdown.

1

What is Data Science?

Real Nigerian examples: banks and loan defaults, hospitals and disease tracking, election patterns.

✓ Connects data science to real Nigerian problems
2

pandas & numpy

Install; load a Nigerian population CSV; .head(), .info(), .describe().

✓ Loads and explores a dataset
3

Data Cleaning

Missing values, renaming columns, fixing types, removing duplicates on a messy student dataset.

✓ Cleans a real dataset
4

Data Analysis

groupby(), value_counts(), describe() — average score by class, most-failed subject, best term.

✓ Extracts insights from grouped data
5

Data Visualisation

matplotlib: bar, line, pie, scatter; visualise performance trends across 3 terms.

✓ Creates 4 types of chart with matplotlib
6

Real Nigerian Dataset

Analyse WAEC pass rates, state population, commodity prices, or road accident data; find 3 insights.

✓ Analyses a real-world dataset
7

Storytelling with Data

3 plain-English insights; present charts and findings.

✓ Communicates data findings clearly
8

Nigeria Data Story Project

Full data analysis report: 3+ charts, written conclusions, recommendation.

✓ Produces a complete data analysis report
End of Term 1 Project

Nigeria Data Story

A Python analysis of a real Nigerian dataset (min. 100 rows) — loading, cleaning, groupby/describe analysis, 3+ matplotlib charts, written conclusions, and one actionable recommendation.

1

What is Freelancing?

Who hires freelancers; research Nigerian Fiverr/Upwork earnings by skill.

✓ Understands the freelancing economy
2

Fiverr Account Setup

Profile photo, display name, description, skills, languages, seller levels.

✓ Creates a complete Fiverr profile
3

What Can I Offer?

Services students can offer now: web design, data entry, Canva design, typing/transcription, Python scripts, Excel models.

✓ Identifies their first freelance service
4

Write a Gig That Sells

Fiverr gig: headline, description, 3 package tiers, FAQ, gallery image.

✓ Writes a compelling service listing
5

Upwork Profile

Title, overview, skills, education, portfolio; first job proposal for a data entry role.

✓ Creates Upwork profile and writes a proposal
6

Portfolio Piece

High-quality sample website for a fictional Nigerian business (restaurant, school, or shop).

✓ Creates a client-ready portfolio piece
7

Product Design — Commercial

Identify a local market product gap; target customer, sketch, business model; one-page pitch document.

✓ Produces a commercial product pitch
8

Pricing Your Services (class exercise)

Setting a freelance rate: exchange rate, platform fees, tax; minimum hourly rate based on living costs. Covers how students price their own freelance work — not EduLab's own tuition pricing.

✓ Sets a data-driven freelance rate
End of Term 2 Project

My Freelance Profile

A complete Fiverr or Upwork profile with a live gig or proposal, plus a portfolio piece — a sample website for a fictional Nigerian business.

1

Capstone Briefing

Choose a real school, community, or family problem to solve with tech; brainstorm 3 options, pick the best.

✓ Defines a real-world capstone problem
2

Capstone Planning

Define solution, users, and tools (Python, Flask, HTML, pandas); 1-page plan and wireframe.

✓ Plans a complete technical project
3

Build — Session 1

Supervised build; instructor supports, doesn't code for students; commit progress at end.

✓ Makes meaningful progress on build
4

Build — Session 2

Continue build, core features; peer review by swapping laptops.

✓ Completes core project features
5

Build — Session 3 & Polish

Fix bugs, improve UI, write README, clean code; must be complete by end.

✓ Delivers a complete, documented project
6

JAMB UTME CBT Mock

Full timed JAMB UTME mock covering Data Processing and Computer Studies; review every wrong answer.

✓ Sits final JAMB readiness mock
7

JAMB Review + Final Prep

Address weak topics from the mock; quick-fire drills; 30-minute timed past questions.

✓ Achieves target JAMB readiness score
8

EduLab Annual Hackathon

Present capstone to a judge panel (school head, EduLab CEO, guest judge); top 3 win prizes; all receive an EduLab Certificate of Digital Competence.

✓ Presents capstone to external audience and earns certificate
End of Term 3 Project

Capstone Project — Annual Hackathon Entry

A complete, documented tech solution (Python, Flask, HTML/CSS, or data tools) with a README, live demo, and a 5-minute presentation to judges at the EduLab Annual Hackathon.
