Primary 6
Computational Thinking and Scratch Projects

Open to new learners at this class level. Begins with a Scratch introduction and builds toward independent educational software.

Age 11–12 years 3 Terms 8 Weeks per Term Tools Scratch (Offline)
Term-by-Term Curriculum

Every Week,
Something Built.

Learners complete three term projects, store their work in a class portfolio, and explain the safety and practical skills used. Select a term to see its full breakdown.

Term outcome: Learn visual-programming foundations and build animated lessons.
1

Scratch from zero

Learn editor, sprites, stage, save/open.

2

Algorithms

Turn a simple explanation into ordered steps.

3

Events and sequences

Start scenes using events and messages.

4

Loops and timing

Repeat actions with timing.

5

Costumes and visuals

Create labelled illustrations.

6

Sound and narration

Add appropriate audio/text explanations.

7

Prototype and test

Review factual clarity and timing.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 1 Assessed Project

Animated Science Explainer

Two-minute Scratch explanation of a science or health concept.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Term outcome: Create a game using conditionals, variables and feedback.
1

Warm-up blocks

Rebuild a basic event and movement script.

2

User input

Ask for answers using sensing.

3

Operators

Compare answers with numbers and strings.

4

Conditions

Choose feedback based on correctness.

5

Variables

Track score and questions completed.

6

Broadcasts

Organise different quiz scenes.

7

Debug and usability

Test wrong answers and reset behaviour.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 2 Assessed Project

Math Practice Game

10-question arithmetic game with scoring, replay and instructions.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Term outcome: Plan, prototype and evaluate an educational Scratch application.
1

Define learning problem

Pick a local topic and target user.

2

Plan user journey

Sketch start, instructions, content and result screens.

3

Create assets

Design sprites/backdrops with readable text.

4

Interactive lesson

Build content with events and sequences.

5

Knowledge check

Add scoring/feedback and safe interactions.

6

Accessibility basics

Improve fonts, keyboard access and contrast.

7

User testing

Collect three testers' feedback and refine.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 3 Assessed Project

Community Learning App

Scratch application teaching a chosen topic with evaluation checklist.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Annual portfolio requirement: Three finished projects (editable files where available), three final exports or screenshots, a weekly skills checklist, and a short learner reflection on what they can now do independently.
