JSS 1
I Understand How Technology Works

Deep computer literacy and first Python.

Age 12–13 years 3 Terms 8 Weeks per Term
Term-by-Term Curriculum

Every Week,
Something Built.

No theory-only sessions — every week ends with something the student made, built, typed, or designed. Select a term to see its full breakdown.

1

History of Computers

Generations, from vacuum tubes to smartphones; timeline activity.

✓ Can explain computer evolution
2

Computer Hardware

Input, output, processing, and storage devices; classify 20 devices; labelled diagram.

✓ Classifies hardware by function
3

Inside a Computer

Disassembly video; label motherboard components — CPU, RAM, GPU, PSU, SATA ports.

✓ Identifies internal components
4

Software Types

System vs application software; list 10 examples each; discuss missing OS.

✓ Distinguishes software categories
5

Operating System

Windows settings: taskbar, Control Panel, Device Manager, File Explorer, task manager.

✓ Navigates OS settings independently
6

Number Systems

Binary (base-2) vs denary (base-10); convert 8-bit binary manually.

✓ Converts between number bases
7

File Types & Management

Extensions (.docx, .pdf, .jpg, .mp4, .exe, .py); organise 30 mixed files.

✓ Identifies file types by extension
8

Computer Manual Project

6-page illustrated Word document explaining computers, written for a Primary 4 audience.

✓ Produces a technical document for non-experts
End of Term 1 Project

Computer Manual

A 6-page illustrated Word document with diagrams, headings, and a glossary.

1

Networks — Types

LAN, WAN, MAN; draw and label examples (school, JAMB CBT centre).

✓ Explains network types with examples
2

Network Devices

Router, switch, modem, hub, NIC, cables; school network diagram.

✓ Describes each network device
3

How the Internet Works

DNS, IP addresses, HTTP vs HTTPS; trace loading EduLab's website.

✓ Traces how a webpage loads
4

Browser Tools

View page source, inspect element; check HTTPS and the padlock icon.

✓ Reads basic browser security signals
5

Cybersecurity Threats

Virus, phishing, ransomware, social engineering case studies.

✓ Identifies 4 types of cyber attack
6

Strong Passwords

Rate 10 passwords; create a school password policy document.

✓ Creates a password security policy
7

Safe Browsing

HTTPS, suspicious links, pop-ups, fake download buttons; online safety quiz.

✓ Identifies unsafe web behaviour
8

Cybersecurity Poster

Canva poster on one cyber threat; present in 2 minutes.

✓ Creates and presents an awareness poster
End of Term 2 Project

Cybersecurity Awareness Poster

A Canva poster on phishing, ransomware, social engineering, or malware — what it is, how it works, how to stay safe.

1

What is Python?

Install Python/IDLE; print('Hello, Nigeria!').

✓ Runs first Python programme
2

Variables

name, age, school variables; f-strings.

✓ Uses variables and f-strings
3

Data Types & Input

Strings, integers, floats; input(); personalised greeting.

✓ Uses input() and data types
4

Simple Calculator

4-function calculator: sum, difference, product, quotient.

✓ Builds a 4-function calculator
5

Conditionals

if/elif/else; number guessing game with 3 chances.

✓ Uses if/elif/else correctly
6

For Loops

Print 1–10; multiplication table via range().

✓ Uses for loop with range()
7

While Loops

Guess number until correct; count tries.

✓ Uses while loop with condition
8

Python Quiz Game

5-question CLI quiz, score tracking, final message.

✓ Completes first complete Python programme
End of Term 3 Project

Python Quiz Game

A CLI quiz (5 questions, own topic), score tracking, feedback per answer, and a final performance message.
