JSS 1
Front-End Web Development — Foundations

Open to new learners at this class level. New entrants begin with no coding assumed. Term 1 HTML, Term 2 CSS, Term 3 JavaScript.

Age 12–13 years 3 Terms 8 Weeks per Term Tools HTML, CSS & JavaScript
Term-by-Term Curriculum

Every Week,
Something Built.

Learners complete three term projects, store their work in a class portfolio, and explain the safety and practical skills used. Select a term to see its full breakdown.

Term outcome: Create semantic multi-page HTML documents.
1

How websites work

Explain browser, website, file and editor; create project folder.

2

First HTML document

Write doctype, html, head, title and body.

3

Text and headings

Use headings, paragraphs, strong and emphasis.

4

Lists and links

Create ordered/unordered lists and internal links.

5

Images and accessibility

Insert local images with alt descriptions.

6

Semantic structure

Use header, nav, main, section and footer.

7

Forms basics and validation

Add labelled inputs; test links and HTML structure.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 1 Assessed Project

My School Information Site

Three linked HTML pages with headings, images, lists and navigation.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Term outcome: Style and lay out an accessible web page.
1

CSS from zero

Style a supplied HTML starter; selectors and rules.

2

Colour and typography

Choose readable font, background and contrast.

3

Box model

Practise margin, padding and borders.

4

Layout with Flexbox

Build a navigation and two-column cards.

5

Images and spacing

Style responsive images and sections.

6

Responsive design

Use media queries for smaller screens.

7

Review design

Fix accessibility, alignment and cross-browser issues.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 2 Assessed Project

Styled School Website

Responsive version of the Term 1 or supplied starter site.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Term outcome: Add basic events and logic to a front-end site.
1

JavaScript introduction

Use script tag, console and variables.

2

Data and operators

Work with strings, numbers and comparisons.

3

Conditions

Display feedback using if/else.

4

Functions

Write reusable functions for user actions.

5

DOM basics

Select and update text and HTML elements.

6

Events and forms

Handle clicks and check form input.

7

Integrate and test

Add interactive quiz or greeting to a starter site.

8

Term project and showcase

Complete, test, present and submit the term project.

End of Term 3 Assessed Project

Interactive Student Portal

Front-end mock student portal with form validation and simple quiz.

Assessment checks: Functional or complete output; accurate key skills; file organisation; explanation; safety and originality.

Annual portfolio requirement: Three finished projects (editable files where available), three final exports or screenshots, a weekly skills checklist, and a short learner reflection on what they can now do independently.
